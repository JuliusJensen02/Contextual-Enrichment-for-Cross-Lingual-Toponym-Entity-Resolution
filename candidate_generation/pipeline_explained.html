Candidate generation pipeline

Two gazetteers describe the same places in different languages. Comparing every record with every record is too expensive, so the pipeline picks the few pairs that are worth comparing: the candidates.

Test sets

Columns used

ColumnWhat it isUsed in
titleThe main name of the place, as written in its own script.Step 3
title_ipaThe title in the International Phonetic Alphabet, so that names in different scripts can be compared letter by letter.Step 2
lat, lonThe coordinates of the place. A record can lack them.Step 1
idIdentifies the record in the candidate pairs.Output

No other column is used: not the name variants, the place type, the country or the description.
