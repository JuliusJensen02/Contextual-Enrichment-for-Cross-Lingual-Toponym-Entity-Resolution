WHY THIS CLEANUP:
=================

The refactored experiments/data_preparation.py replaces the functionality
of the archived scripts by providing a unified data loading interface that:

1. Loads full records (cached by dataset only) → 88x speedup
2. Builds complete Pair objects with candidates  
3. Filters attributes to requested categories at query time

This eliminates the need for:
- Separate data preparation steps per dataset
- Multiple dataset-specific loaders
- Attribute-based caching (now done at dataset level only)

For more details on the new architecture:
See experiments/ARCHITECTURE.md and experiments/README.md
